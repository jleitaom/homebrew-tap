# jleitaom/homebrew-tap

Homebrew casks for [Gutter](https://github.com/jleitaom/gutter), the menu bar app that fits new
windows beside the Stage Manager strip.

```sh
brew install --cask jleitaom/tap/gutter
```

Gutter isn't notarized by Apple, so the first time you open it macOS says it can't verify the
app. Open **System Settings → Privacy & Security**, scroll down and click **Open Anyway**. You only
need to do this once. Gutter updates itself after that.

`Casks/gutter.rb` is updated by Gutter's release workflow; don't edit it by hand.
